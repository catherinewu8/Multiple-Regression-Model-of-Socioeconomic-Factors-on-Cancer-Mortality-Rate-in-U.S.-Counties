# Multiple-Regression-Model-of-Socioeconomic-Factors-on-Cancer-Mortality-Rate-in-U.S.-Counties
The goal of this study is to investigate the effects of various socioeconomic factors on cancer mortality in various U.S. counties. In this study, a predictive model of the rate of cancer mortality per 100,000 residents of various U.S. counties was constructed using multiple linear regression to investigate this relationship. Report generated with LaTeX and calculations performed with R.
